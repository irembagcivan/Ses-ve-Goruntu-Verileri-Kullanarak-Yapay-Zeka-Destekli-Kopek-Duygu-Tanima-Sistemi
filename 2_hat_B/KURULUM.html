Tam paketle ilk kurulum

ZIP'i bütünüyle bir klasöre çıkarın. ZIP içinden program çalıştırmayın. Python 3.11 kullanımı mevcut ortamda test edilmiştir. Sanal ortam herkese kendi bilgisayarında kurulmalıdır; Mac sanal ortamını Windows'a kopyalamayın.

Mac / Linux:

python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-share.txt
python -m src.demo.launch --check-only
python -m src.demo.launch

Windows PowerShell:

py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements-share.txt
.\.venv\Scripts\python.exe -m src.demo.launch --check-only
.\.venv\Scripts\python.exe -m src.demo.launch

Kurulumdan sonra Mac'te START_ANALYSIS.command, Windows'ta START_ANALYSIS.bat kullanılabilir. Tarayıcı otomatik açılır. Açılmazsa: http://127.0.0.1:8768

requirements-share.txt, şu anda çalışan temel paket sürümlerini sabitler. Tüm geçişli bağımlılıkları içeren platformlar arası bir kilit dosyası değildir. Yeni Windows/Linux kurulumu ayrıca doğrulanmalıdır; mevcut gerçek çıkarım testleri bu Mac'te yapılmıştır. Root requirements.txt daha genel geliştirme aralıklarıdır; paylaşım uygulaması için requirements-share.txt dosyasını tek başına kullanın.

Yeni videoda segmentasyon

Video yükle ve analizi başlat. Köpek pozu, ses olayları ve sekiz davranış modeli karşılaştırmasının yanında renkli segmentasyon videosu ve siyah-beyaz maske görünür. Her örnek için PNG maskeleri ve zaman damgalı JSON indirilebilir. Maskeler dikdörtgen kutulardan türetilmez; ön-eğitimli segmentasyon ağı piksel düzeyinde tahmin eder.

İlk 60 saniye analiz edilir. Maske videosu en fazla 8 kare/sn ve uzun kenarı 960 piksel olarak işlenir; indirilen maskeler bu görüntü boyutuna karşılık gelir. Kare içindeki köpek numaraları kalıcı birey kimliği değildir. Gerçek maske etiketleri olmadığından IoU/Dice başarısı ölçülmemiştir. Segmentasyon mevcut davranış ağlarını bu maskelerle yeniden eğitmez; önceki F1 skorları değişmez.
